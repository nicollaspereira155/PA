# 💻 Programação e Algoritmos

Repositório destinado à organização dos arquivos desenvolvidos durante as aulas de **Programação e Algoritmos (PA)**.

Aqui estão reunidos exercícios, atividades e lições realizados ao longo das aulas, servindo como um registro do meu aprendizado e da minha evolução na programação.

## 📚 Sobre o repositório

Este repositório foi criado com o objetivo de manter os arquivos das aulas organizados e facilitar o acesso aos conteúdos e exercícios desenvolvidos durante o curso.

Os arquivos podem incluir:

- 📝 Exercícios propostos em aula
- 💻 Códigos desenvolvidos durante as atividades
- 📖 Lições e conteúdos trabalhados
- 🧠 Atividades para prática de lógica e programação
- 📂 Outros materiais relacionados à disciplina

## 🎯 Objetivo

O principal objetivo deste repositório é **organizar e registrar minha trajetória de aprendizado em Programação e Algoritmos**, permitindo acompanhar minha evolução conforme novos conteúdos e exercícios são desenvolvidos.

Além disso, o repositório pode ser utilizado para:

- Revisar conteúdos das aulas;
- Consultar exercícios já realizados;
- Praticar programação;
- Acompanhar minha evolução durante o curso;
- Manter meus trabalhos escolares organizados no GitHub.
